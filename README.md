# Dream Job Finder - AI-Powered Job Search

A modern, responsive web application that helps users find jobs across multiple portals using AI-powered search. Built with Next.js, TypeScript, and React.

## 🌟 Features

- **AI-Powered Job Search**: Search across multiple job portals simultaneously
- **Dynamic Job Portals**: Uses Perplexity AI to dynamically determine the most relevant job portals based on role and location
- **Dynamic Popular Jobs & Locations**: Uses Perplexity AI to generate current trending job roles and locations
- **Job-Focused Chatbot**: Interactive AI assistant in the bottom-right corner for job-related queries only
- **Cross-Platform Compatibility**: Works on all devices and browsers
- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Modern UI/UX**: Beautiful glassmorphism design with smooth animations
- **Accessibility**: WCAG compliant with keyboard navigation support
- **PWA Support**: Installable as a mobile app

## 🤖 Perplexity AI Integration

This application uses Perplexity AI to dynamically generate popular job roles, trending locations, determine the most relevant job portals based on current market trends, and power the job-focused chatbot. The AI analyzes current job market data and provides up-to-date suggestions.

### How it works:
1. **Dynamic Job Portals**: Job portals are dynamically selected based on the job role and location using Perplexity AI
2. **Dynamic Content**: Popular jobs and locations are generated by Perplexity AI instead of being hardcoded
3. **Job-Focused Chatbot**: Interactive AI assistant that only responds to job-related queries
4. **Market Trends**: The AI considers current market trends, emerging technologies, and popular cities
5. **Fallback System**: If Perplexity AI is unavailable, the app gracefully falls back to curated static data
6. **Real-time Updates**: Content updates automatically when the page loads

### Available Job Portals:
- **Naukri**: Indian job portal
- **Indeed**: Global job search
- **LinkedIn**: Professional networking
- **Glassdoor**: Company reviews and jobs
- **Monster**: Job search platform
- **TimesJobs**: Indian job portal
- **Shine**: Indian job search
- **HackerRank**: Tech jobs
- **Upwork**: Freelance platform
- **Freelancer**: Freelance marketplace

### Setup:
1. Get your Perplexity AI API key from [https://platform.perplexity.ai/](https://platform.perplexity.ai/)
2. Add it to your `.env.local` file as `PPLX_API_KEY`
3. The app will automatically start using dynamic content and enable the chatbot

### Job-Focused Chatbot:
- **Location**: Bottom-right corner of the screen
- **Functionality**: Only responds to job-related queries (resume tips, interview prep, career advice, etc.)
- **Job Search**: Can search for jobs directly in the chat (e.g., "search for software engineer jobs in New York")
- **Restrictions**: Automatically redirects non-job-related conversations back to job topics
- **Features**: 
  - Real-time chat with typing indicators
  - Message history within the session
  - Clear chat functionality
  - **Interactive job search results** with clickable job listings
  - Responsive design that works on all devices
  - Theme-aware styling (matches your selected theme)
  - AI-powered job title and location extraction from natural language

## 🔧 Configuration

### Environment Variables
Create a `.env.local` file:
```env
# Perplexity AI Configuration (Required for dynamic content and chatbot)
# Get your API key from https://platform.perplexity.ai/
PPLX_API_KEY=your_perplexity_api_key_here

# Adzuna Configuration (Optional - for job listings)
ADZUNA_APP_ID=your_adzuna_app_id_here
ADZUNA_APP_KEY=your_adzuna_app_key_here
```

The app includes automatic browser detection and feature polyfills. No additional configuration needed.
